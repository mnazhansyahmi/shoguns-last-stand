# Shogun's Last Stand

**Free public playtest · v0.1.0 · Windows x64**

Hold the village gate against the undead. Fight with your katana, summon an army
and spend your rewards on upgrades between battles.

## In this playtest

- Five campaign stages in **Bamboo Outskirts**, ending with **The Fallen Daimyo**.
- A three-hit katana combo, heavy strike, dash, Spirit Slash and a charged Ultimate.
- Unlock the Bow and War Cry as you progress.
- Six summonable allies: Ashigaru, Yumi Archer, Shrine Healer, Spear Guardian,
  Onmyoji and Hatamoto.
- Command allies to charge or hold. Buy upgrades with earned gold and keep your progress.
- Painted ink characters against a sunset bamboo landscape, with music and sound effects.

This is an early public playtest. I want to hear how the combat feels, which
stages are too easy or frustrating, and what needs explaining more clearly.

## Download and play

Download the Windows ZIP, extract the entire folder, then open
**ShogunsLastStand.exe**. Keep the `.pck` file beside it. You do not need Godot.

**Windows x64 only.** A graphics driver supporting OpenGL 3.3 is required.
No browser or mobile build is included in this release.

## Keyboard controls

| Action | Key |
| --- | --- |
| Move | A / D or arrow keys |
| Attack / heavy / dash | J / K / L |
| Spirit Slash / Ultimate | U / I |
| Bow / War Cry | E / Q (unlocked through progression) |
| Allies charge / hold | F |
| Summon | 1–6 or click an unlocked portrait |
| Pause / back | Esc |

The game includes controller mappings and on-screen touch controls. Open
**Settings → Controls** for the complete layout. Physical-controller hardware
testing is still pending. Settings also offers reduced decorative motion and
toggles for blood and screen shake.

## Tell me what you think

Please leave a comment with:

1. Which stage you reached.
2. What felt good about the combat.
3. What felt confusing, unfair or repetitive.
4. Any bug and the steps needed to reproduce it.

Screenshots or short clips are especially useful. Include the build version
**0.1.0** when reporting a problem.

## Known playtest limitations

Balance, movement animation and performance are still being refined. Testing
has covered the development Windows machine; wider PC compatibility feedback is
welcome. The next content update will be decided after this feedback round.
