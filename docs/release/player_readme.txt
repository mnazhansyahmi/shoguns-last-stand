SHOGUN'S LAST STAND
v0.1.0 - Free Public Playtest - Windows x64

PLAY
Extract the whole ZIP into a folder. Run ShogunsLastStand.exe.
Keep ShogunsLastStand.pck beside the executable.
Godot and the source project are not needed to play.

Fight the undead with your katana, summon allies and defend the village gate.
This playtest includes five campaign stages in Bamboo Outskirts, six unlockable
allies, persistent upgrades and The Fallen Daimyo boss encounter.

KEYBOARD
A / D or Left / Right: Move
J: Attack (three-hit combo)
K: Heavy strike
L: Dash
U: Spirit Slash
I: Ultimate (when the portrait ring is full)
E: Bow (unlocks after clearing stage 1)
Q: War Cry (unlocks after clearing stage 2)
F: Allies charge / hold
1-6 or click a summon portrait: Summon an unlocked ally
Esc: Pause / back

GAMEPAD
Left stick or D-pad left/right: Move
X / Square: Attack        Y / Triangle: Heavy
A / Cross: Dash           B / Circle: Allies charge / hold
RB / R1: Spirit Slash     LB / L1: War Cry
RT / R2: Bow              LT / L2: Ultimate
D-pad up/down: Select summon; right-stick click (R3): Summon selected ally
Menu / Options: Pause
Controller support is implemented; a physical-controller hardware test is pending.

SETTINGS
Settings includes volume, controls help, touch controls, reduced decorative
motion, blood, screen shake and Reset Progress (with confirmation).

SAVES
The public Windows build stores progress and settings in:
%APPDATA%\ShogunsLastStand
Keep this folder when replacing the game files with a future update.
Developer/editor saves remain in their original Godot app_userdata location.
Do not use Reset Progress unless you want to erase your public-playtest progress.

PLAYTEST NOTES
This is an early public playtest, not the finished v1.0 release.
Balance, animation and performance are still being refined.
Currently Windows x64 only. No browser, macOS, Linux or mobile build is included.
Uses the Godot Compatibility renderer; requires a graphics driver supporting
OpenGL 3.3. It has been tested on the development Windows machine, not a broad
range of PCs.
