# Quality bar — existing ink game world

This is a scoped refinement, not a new visual-world choice or comp reproduction.
The user's six playtest screenshots and `direction.md` govern the result.

| Dimension | Required visible result |
| --- | --- |
| Character | Same slim bareheaded identity, fuller calves and torso, connected painted joints, fixed bone lengths and soles. |
| Motion | Purposeful speed-matched strides, no hard support-foot pelvis snap, planted-foot stability, run-to-idle settlement; record actual playback for user judgment. |
| Skills | Compact round cached figure pictures from the user's third screenshot, with key badges, sweep, glow and lock layers. |
| Results | Battle celebration with crest, large earned totals and XP progress; no giant opaque text box. Preserve reward truth, replay disclosure, unlocks, save errors, input and button spacing. |
| Menu | Dimensional painted rock, shadows touching soles, matching dusk/warm light and restrained free cloth/hair motion; no limb rig. |
| Verification | Full suite, real renderer evidence on desktop and wide phone, performance probe with actual results. Stills cannot certify continuous gait smoothness. |

No new font, palette, campaign content, gameplay stats or external assets are required.
Native Godot has no DOM/CSS detector. Review fixes material scope mismatches once,
confirms the correction and stops; documentation then records the shipped system.
